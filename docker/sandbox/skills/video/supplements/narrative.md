# Narrative

Build the story before choosing visuals.

- State the audience, promise, evidence, and desired final action in plain
  language.
- Organize beats by change in understanding: establish context, create a useful
  question or tension, reveal the answer, support it, then resolve.
- Give each beat one job. Combine adjacent beats with the same job and remove
  beats that add no new meaning.
- Open with specific value or tension, not a generic title. End with a concrete
  implication or action, not a summary of every prior point.
- Preserve factual qualifiers, units, attribution, and uncertainty from source
  material. Never strengthen a claim for dramatic effect.
- Let visuals add evidence, structure, or contrast. They should not simply
  duplicate every spoken sentence as on-screen text.
- Maintain continuity: an object, question, or visual relationship introduced
  in one beat should evolve or resolve later when useful.
- Prefer a clear argument over feature enumeration. If several points matter,
  group them under the decision they help the viewer make.
